# Lint & Code Quality

Ruff is the single linter + formatter for this repo (fast, replaces flake8/isort/black).
Config lives in `pyproject.toml` under `[tool.ruff]` — **explicit rule selection**, not
defaults, so a ruff upgrade can never silently change the gate.

## Run

```bash
uv run ruff check .            # lint
uv run ruff check . --fix      # apply safe autofixes
uv run ruff format .           # format (or --check in CI)
```

CI (`.github/workflows/ci.yml`) runs `ruff check` + `ruff format --check` on every push/PR
**before** the test suite — style breakage fails fast, cheaply.

## Rule set (why these)

| Group | Rules | Rationale |
|---|---|---|
| `E`, `W` | pycodestyle | baseline hygiene |
| `F` | pyflakes | unused imports/vars — caught a real duplicated-import bug (F811) |
| `I` | isort | deterministic import order |
| `UP` | pyupgrade | modern py311 idioms (`datetime.UTC`, f-strings) |
| `B` | bugbear | real bug patterns (loop vars, mutable defaults, `zip` strictness) |
| `C4` | comprehensions | clearer collection building |
| `SIM` | simplify | flatter control flow (`contextlib.suppress`, `return not …`) |
| `S` | bandit | security smells — subprocess, asserts, hardcoded secrets |
| `PLW` | pylint warnings | e.g. `subprocess.run` without `check=` |
| `TRY` | exception hygiene | no pointless try blocks, no swallowed exceptions |
| `RUF` | ruff-specific | unused noqa, zip strict, unused unpacked vars |

Deliberate ignores (documented in `pyproject.toml` with inline comments):

- `B008` — `Depends()`/`Query()` in defaults IS the FastAPI idiom.
- `RUF001/002/003` — ambiguous-unicode noise on bilingual (CJK) comments/docstrings.
- `PLW0603` — `global` for lazy Redis singleton in `app/core/db.py`, by design.
- `TRY003` — long `HTTPException(detail=…)` messages are the API error style.
- `UP042` — keep `(str, Enum)`: `StrEnum` changes `str()` semantics used in responses.
- `FURB157` — money code keeps string `Decimal("…")` constructors for precision consistency.

Per-file ignores are minimal and each carries a reason: test asserts (`S101`), localhost
dev tooling (`S310/S603/S607`), smoke-script asserts, autogenerated migrations excluded
from style gating.

Baseline on the hardening commit (`9ab0ea2`): **66 lint errors, 45 files unformatted**.
After this pass: **0 errors, 0 unformatted**, suite still **120/120 green**.

- **58 auto-fixed** (`ruff check --fix`): unused imports (12× F401), `timezone.utc → UTC`
  (11× UP017), import sorting (9× I001), unused noqa (5× RUF100), redefined imports
  (2× F811 — duplicated `mask_phone`/`assert_driver_transition` imports in `drivers.py`).
- **~28 fixed by hand**, the ones autofix deliberately skips because they change
  behaviour shape:
  - `UP031` ×9 — `%`-formatting → f-strings in tests/scripts;
  - `E501` ×5 — long lines wrapped (incl. two `client.post(...)` calls in tests);
  - `PLW1510` ×3 — `subprocess.run(...)` in scripts gained explicit `check=False`;
  - `S110`/`TRY300`/`SIM105` — `grab_service.grab()` restructured `except: raise` +
    `return True` into a `try/finally` with the return moved out (lock still always
    released, DB failures still propagate — verified by the 6-way concurrency test);
  - `TRY203`, `SIM103`, `SIM115`, `RUF005`, `RUF059`, `B905`, `B007` — one-off cleanups
    (useless try, `return not x`, `noqa` on the intentionally-inherited log handle,
    `zip(..., strict=True)`, unused unpacked var).
- **45 files reformatted** (`ruff format`), quote style `"double"`, line length 100.

No dependency added: ruff was already a dev dependency; this pass only tightened usage
and codified the gate in CI.
