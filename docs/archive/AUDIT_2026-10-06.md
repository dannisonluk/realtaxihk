## Executive Summary

1. Backend 的 auth、RBAC、CSRF、refresh rotation、transaction ordering 大多係刻意設計且有大套 regression tests；fresh audit 搵到 3 個 High：admin cookie `__Host-` 與窄 path 衝突、X-Forwarded-For 單 hop 信任錯誤、OTP/email send 早過 commit。
2. Mobile 最弱係 realtime/location 生命週期：socket 唔重連、driver push 入 closed channel、passenger REST snapshot 可 race 覆寫新 socket data；另有 permission denial 喺 active-trip streaming path 冇處理。
3. Admin console 最弱係手動管理嘅 async path：dialog submit 冇 function-entry busy guard、settlement preview/run/export 冇 request identity、refunds/destinations 有 stale data 或 hardcoded English。
4. Fresh audit 亦推翻一個舊結論：mobile 其實有 `tool/verify_contract.dart`，64 個 fixtures 全部會經真實 `fromJson` decode（`0 failure`）；「fixtures 從未 parse」係 false positive。
5. 收尾 gate：backend full pytest `1245 passed`（719.21s）、admin `tsc` clean + vitest `87 passed`、mobile `dart_check` 85/0/0 + harness `155 passed` + contract `64/64`；未修項全部係 Low / documented tradeoff，詳見下方表格。
